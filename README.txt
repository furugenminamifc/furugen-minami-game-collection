古堅南FC ゲームコレクション Ver.4.3.0
AIディフェンダー搭載版

【新機能】
・AIディフェンダーが選手を発見すると追跡
・ディフェンダーごとに視界範囲、反応速度、追跡速度を設定
・難易度に応じてAIの強さが変化
・やさしい：視界が狭く、追跡速度が遅い
・ふつう：標準的な追跡AI
・むずかしい：視界が広く、追跡速度が速い
・追跡中のディフェンダー人数をリアルタイム表示
・警戒範囲を半透明の円で表示
・待機中は左右移動、発見後は選手とボールを予測して追跡
・AI突破成功、接触、時間切れの専用メッセージ

【継承機能】
・スマホ専用縦長レイアウト
・PC専用ワイドレイアウト
・選手選択、難易度、制限時間、ポイント、突破数、ライフ
・ドリブルランキング
・PKチャレンジ Ver.4.1.3
・PWA／オフライン対応
